TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "clasp: command not found"
Solution: 
  npm install -g @google/clasp

Problem: "User has not enabled the Apps Script API"
Solution:
  1. Go to: https://script.google.com/home/usersettings
  2. Turn ON "Google Apps Script API"
  3. Try again: clasp login

Problem: "Access not configured"
Solution:
  clasp login --creds

Problem: "Already cloned to another location"
Solution:
  # Check which project is linked:
  cat .clasp.json
  
  # If wrong Script ID, delete and re-clone:
  rm .clasp.json
  clasp clone 1gCyB7vsSSbpPhj-Lu6LCFmRGjsqqOorIchsOwvJWg3JjFQJP0xsg_edi

Problem: "Push failed - undefined error"
Solution:
  # Make sure you're in the RIGHT repository!
  pwd
  # Should show: /path/to/mm-system
  
  # Make sure Welcome.gs is excluded:
  grep "Welcome.gs" .claspignore
  # Should show: Welcome.gs

Problem: "Can't find repository"
Solution:
  # Find all mm-system folders:
  find ~ -name "mm-system" -type d 2>/dev/null
  
  # CD to the correct one
  cd /path/shown/above
