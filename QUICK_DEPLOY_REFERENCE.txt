═══════════════════════════════════════════════════════════════════
  📞 TROUBLESHOOTING QUICK TIPS
═══════════════════════════════════════════════════════════════════

Registration stuck?
  → MM_resetRegistration() and try again

Plaid not working?
  → Check PLAID_CONFIG in Config.gs
  → Verify CLIENT_ID, SECRET, LINK_KEY are set

Transactions not importing?
  → Check Apps Script logs (View → Logs)
  → Look for "writePlaidTransactionsToSheet"
  → Verify ACCOUNT 1 sheet exists

PIN modal not showing?
  → Run MM_openSecurityThenDashboard()
  → Check logs for "🔐 Showing PIN login gate"

Clarity AI errors?
  → Ensure INCOME/EXPENSE TRANSACTIONS sheets exist
  → Verify sheets have data in Date, Description, Amount columns
