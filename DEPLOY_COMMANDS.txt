QUICK DEPLOY COMMANDS - Copy & Paste These
═══════════════════════════════════════════════════════════════

STEP 1: Install clasp (one-time setup)
───────────────────────────────────────
npm install -g @google/clasp


STEP 2: Login to Google (one-time setup)
───────────────────────────────────────
clasp login


STEP 3: Get Your Script ID
───────────────────────────────────────
1. Open your Google Sheet
2. Extensions → Apps Script
3. Project Settings (gear icon)
4. Copy the "Script ID"


STEP 4: Navigate to project folder
───────────────────────────────────────
cd /home/user/webapp


STEP 5: Clone your Apps Script project
───────────────────────────────────────
clasp clone YOUR_SCRIPT_ID_HERE

(Replace YOUR_SCRIPT_ID_HERE with actual ID from Step 3)


STEP 6: Push all files to Apps Script
───────────────────────────────────────
clasp push --force


STEP 7: Open in browser to verify
───────────────────────────────────────
clasp open


STEP 8: Test the deployment
───────────────────────────────────────
Open your Google Sheet and test login/registration flow

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Error: "Not logged in"
→ Run: clasp login

Error: "No .clasp.json file"
→ Run: clasp clone YOUR_SCRIPT_ID

Error: "Push failed"
→ Run: clasp push --force

Error: "Function not found"
→ Delete old Welcome.gs in Apps Script manually
→ Run: clasp push --force
